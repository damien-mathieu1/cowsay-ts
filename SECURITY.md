# Security Policy

cowsay-ts has no runtime dependencies and does not execute, fetch, or write
anything — it formats strings. Still, if you find a security issue (e.g. in
the build/publish pipeline), please report it privately rather than opening
a public issue.

## Reporting

Email damien.mathieu.pro@gmail.com, or use
[GitHub's private vulnerability reporting](https://github.com/damien-mathieu1/cowsay-ts/security/advisories/new).

Expect an initial response within a few days. Supported: the latest
published version only.
